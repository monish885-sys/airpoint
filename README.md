# Airpoint

Webcam hand control playground built with [p5.js](https://p5js.org/) and [ml5.js HandPose](https://docs.ml5js.org/).

**Gestures**
- Cursor follows the midpoint between your thumb tip and index fingertip
- Pinch = tap / grab
- Pinch + hold = drag (release to fling)
- Hold still ~1s = dwell tap

## Run locally

```bash
python3 -m http.server 8766
```

Open [http://127.0.0.1:8766/](http://127.0.0.1:8766/) and allow camera access.
